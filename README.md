# SimpleBill — Free Invoice Generator

Create professional invoices in seconds. No sign-up, no ads, no data collection.

🌐 **Live**: https://simplebill.vercel.app

## Features

- 🎨 3 beautiful templates (Modern, Classic, Minimal)
- 📄 Real-time preview
- 💾 Auto-save to browser (never lose your work)
- 📥 Export as PDF (browser print)
- 📤 Save/Load invoice drafts as JSON
- 💱 Multi-currency support (USD, EUR, GBP, CNY, JPY, CAD, AUD)
- 🖨 Print-friendly
- 📱 Responsive (works on mobile)

## Tech Stack

- Pure HTML/CSS/JS — zero dependencies
- Font Awesome for icons
- Inter font from Google Fonts
- localStorage for persistence
- Deployed on Vercel

## Development

```bash
# Start local dev server
python -m http.server 8080
# or
npx serve .
```
