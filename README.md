## 🎯 Features

### Free
- **3 Templates** — Modern, Classic, Minimal
- **Real-time preview** — See changes as you type
- **Multi-currency** — USD, EUR, GBP, CNY, JPY, CAD, AUD
- **Tax calculation** — Add tax rate, auto-calculated
- **Auto-save** — Never lose your work (localStorage)
- **PDF export** — Print or save as PDF
- **JSON save/load** — Backup and restore invoices
- **Keyboard shortcuts** — `Ctrl+S` save, `Ctrl+P` print

### Pro ($5 lifetime)
- **6 Premium Templates** — Elegant, Bold, Clean & more
- **CSV/Excel Import** — Bulk import line items from spreadsheets
- **Batch Generation** — Create multiple invoices at once
- **Custom Branding** — Logo, colors, custom fonts
- **No Watermark** — Clean, professional PDFs
- **Priority Support** — Email help within 24h

## 🚀 Getting Started

Simply visit https://arker-newton.github.io/simplebill/ and start typing. No installation needed.

### For developers

```bash
git clone https://github.com/Arker-Newton/simplebill.git
cd simplebill
python -m http.server 8080
# Open http://localhost:8080
```

### Tech Stack
- Pure HTML/CSS/JS — **zero dependencies**, zero frameworks
- Font Awesome 6 for icons
- Inter font from Google Fonts
- localStorage for persistence
- Deployed on **GitHub Pages**
